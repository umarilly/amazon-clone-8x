# Amazon Clone (8x Take-Home Assignment)

A 24-hour clone of the Amazon.com shopping experience, built with Next.js
(App Router), TypeScript, and Tailwind CSS. Scope, milestones, and
acceptance criteria live in `ASSIGNMENT_CONTEXT.md`.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the current
milestone.

## Repo structure

```
data/            mock product catalog (JSON)
src/app/         routes (Next.js App Router)
src/components/  shared UI components
src/lib/         data access + helpers
.agent-logs/     per-session AI agent transcript log (committed, do not edit)
```
